# Chinese Study / Mandarin Studio

A standalone visual prototype for a Chinese study dashboard called Mandarin Studio.

The app is a Vite, React, and TypeScript frontend with a dark scenic liquid-glass interface. It currently uses mock data and browser localStorage only. There is no backend, auth, database, API, or deployment setup yet.

## Tech Stack

- Vite
- React
- TypeScript
- Lucide React icons
- CSS glassmorphism styling

## Local Setup

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Open:

```text
http://127.0.0.1:5199/
```

## Build

```bash
npm run build
```

## Lint / Type Check

```bash
npm run lint
```

## Current Scope

- Dashboard
- Lessons
- YouTube
- Vocabulary
- Anki
- Review
- Settings

All app data is mock/localStorage data for prototype review.
